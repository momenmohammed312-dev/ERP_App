## 2. القيمة والسبب التجاري

- **المشكلة التي يحلها:** عدم وجود استشراف ذكي أو تنبيهات استباقية لمعدل نفاد البضائع أو الشذوذ في الورديات (كزيادة المرتجعات أو الخصومات المريبة) أو ركود العملاء والديون.
- **النتيجة المتوقعة:** تنبيهات استباقية تلقائية لصاحب العمل دون أي تكلفة مادية أو اشتراكات شهرية، تعمل أوفلاين 100%، مع واجهة إشعارات مخصصة نظيفة خالية من الأيقونات المشتتة، وصفحة تحليل ذكي مخصصة داخل التقارير.
- **لو اتأجل، ما الضرر:** ضياع مبيعات بسبب نفاد السلع المفاجئ، وصعوبة اكتشاف التسريب المالي في الورديات.

## 3. المتطلبات (Requirements)

**يجب أن يفعل (Must):**
1. حساب معدل الاستهلاك اليومي والتنبؤ بموعد نفاد الأصناف بدقة بناءً على مبيعات آخر 14/30 يوم.
2. كشف الشذوذ المالي (طفرات المرتجعات، الإلغاءات، الخصومات غير الطبيعية في الوردية).
3. كشف ركود العملاء المعتادين وانقطاعهم عن الشراء وتأخر السداد.
4. صفحة مخصصة للإشعارات (`SmartNotificationsScreen`) بتصميم ناصع ونظيف وخالٍ من الأيقونات داخل البنود.
5. صفحة مخصصة للتحليل الذكي داخل قسم التقارير (`SmartAnalyticsReportPage`).
6. تشغيل الفحص الذكي تلقائياً عند فتح شاشة البرنامج الرئيسية وعند إقفال الوردية.
7. تكلفة صفرية 100% تعمل على SQLite / Drift أوفلاين مع خيار Gemini API Free Tier للملخص البشري.

**لا يجب أن يفعل (Out of scope):**
- تعديل أو كسر أي ترحيل قاعدة بيانات قديم.
- فرض أي واجهات سحابية مدفوعة.
- استخدام أيقونات داخل بنود الإشعارات المنفردة بناءً على طلب المستخدم.

## 4. معايير القبول (Acceptance Criteria)

- [x] AC1: حساب الأيام المتبقية قبل نفاد السلع بدقة وتوليد إشعار تنبؤي إذا كان المتبقي <= 3 أيام.
- [x] AC2: رصد طفرات المرتجعات غير المعتادة للوردية وإصدار تنبيه شذوذ مالي عند إغلاق الوردية أو الفحص.
- [x] AC3: وجود صفحة مخصصة للإشعارات خالية من الأيقونات المشتتة مع تصنيفات نصية رقيقة وحالات مقروء/غير مقروء.
- [x] AC4: وجود صفحة مخصصة داخل قسم التقارير تعرض مؤشرات الذكاء والاستشراف المالي والسلعي.
- [x] AC5: فحص تلقائي يعمل بسلاسة عند فتح اللوحة الرئيسية وإغلاق الوردية بدون أي بطء أو تعطيل لواجهة المستخدم.
- [x] AC6: دعم كامل للغة العربية والاتجاه RTL وعدم التأثر بانقطاع الإنترنت.
- [x] AC7: إمكانية تفعيل أو تعطيل الميزة للمستخدمين بسهولة عبر الإعدادات (`SettingsService.isSmartAnalyticsEnabled`).
