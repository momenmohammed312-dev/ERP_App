## 2. القيمة والسبب التجاري

- **المشكلة التي يحلها:**
  1. عدم إمكانية البحث والإضافة المباشرة في شاشة المنتجات والعودة تلقائياً عند كتابة منتج أو مادة خام غير موجودة في الوصفة أو الأمر.
  2. ظهور أصناف "تصنيع للغير (عهدة العميل)" في شاشة المخزن الرئيسي والكاشير بكمية صفر وسعر صفر.
  3. عدم تزامن الكمية المخططة (مثل 500) بين الوصفة والأمر والمرحلة الأولى، وظهور حقول "التشغيل للغير" في نافذة الأمر الداخلي.
  4. حصر المخرجات في "المقاسات (ملابس)" فقط وعدم ملاءمتها لمصانع الأخشاب والأثاث والتجميع والتعبئة، مع غياب أزرار تعديل وحذف المراحل والمخرجات وتكرار المقاسات وظهور كميتها 0.0.
  5. غياب جدول واضح لمتابعة وتعديل المواد الخام المستهلكة فعلياً في التصنيع الداخلي وعدم إمكانية سحب خامات إضافية غير مسجلة بالوصفة (مثل مسامير، غراء، دهان).
  6. تقرير مراحل وتكاليف الأمر يطبع صفحة بيضاء، وبطاقة الإنتاج/الصرف تطبع جداول عهدة عميل فارغة لأمر تصنيع داخلي.
- **النتيجة المتوقعة:** تجربة مستخدم متكاملة وسلسة للتصنيع الداخلي تناسب كافة الأنشطة الصناعية مع تقارير PDF منسقة بدقة.

## 3. المتطلبات (Requirements)

**يجب أن يفعل (Must):**
1. دعم البحث النصي الذكي في حقول المنتجات والخامات والعملاء، مع زر للانتقال لشاشة المنتجات لإضافة الصنف والعودة تلقائياً واختياره.
2. عزل أصناف عهدة العملاء (`productType: 'custody_only'`) عن المخزن الرئيسي والكاشير.
3. تزامن كمية الوصفة مع كمية الأمر والمرحلة الأولى، وإخفاء حقول تشغيل للغير في الأوامر الداخلية.
4. تعميم المراحل والمخرجات لتشمل (المواصفة / الجزء المجمّع / المقاس) مع قوالب جاهزة للأخشاب والملابس والتعبئة وعام، وحفظ المسميات تلقائياً، وإضافة أزرار التعديل والحذف ومنع تكرار الصنف.
5. جدول استهلاك خامات مرن في شاشة تفاصيل الأمر الداخلي يتيح تعديل الكميات وإضافة خامات إضافية للأمر.
6. إصلاح تقرير تكاليف الأمر PDF وبطاقة التشغيل والصرف للورشة في `UnifiedPrintService`.

## 4. معايير القبول (Acceptance Criteria)

- [x] AC1: عند البحث عن منتج أو مادة خام غير موجودة في حقل البحث، يظهر زر ينقل لشاشة المنتجات مع تمرير الاسم، وفور الحفظ يعود لنفس النافذة ويختار الصنف تلقائياً.
- [x] AC2: أصناف عهدة العملاء لا تظهر في شاشة المنتجات الرئيسية ولا الكاشير.
- [x] AC3: اختيار الوصفة يملأ كمية الأمر تلقائياً، وتعديل كمية الأمر يحدّث كمية المرحلة الأولى، ولا تظهر حقول أجر التشغيل للغير في الأمر الداخلي.
- [x] AC4: مراحل الإنتاج تدعم أزرار التعديل والحذف، والمخرجات تدعم الأخشاب والتجميع والملابس بدون تكرار وبدون كمية 0.0 عند الإنشاء.
- [x] AC5: تفاصيل الأمر الداخلي تعرض جدول الخامات المستهلكة مع إمكانية التعديل وسحب خامات إضافية.
- [x] AC6: مطبوعات PDF تطبع الجداول والبيانات كاملة بدون صفحات بيضاء وبدون جداول عهدة عميل فارغة للأمر الداخلي.
- [x] AC7: نجاح كافة اختبارات الوحدة وخلو التحليل الساكن من الأخطاء.
