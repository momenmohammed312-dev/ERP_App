## ⭐ اكتشاف أثناء التنفيذ

**الـinstallers كانت تستهدف مساراً خاطئاً:**

| | |
|---|---|
| ما تحذفه الـinstallers | `%APPDATA%\com.example\pos_offline_desktop` |
| أين يكتب التطبيق فعلياً | `%APPDATA%\pos_offline_desktop` — `secure_license_storage.dart:14` |

**⇒ الحذف كان `no-op` في الواقع ⇒ lattices أن العملاء لم يفقدوا رخصهم عند التحديث.** لكن هذا **لغم مؤجَّل**: أي «إصلاح» للمسار مستقبلاً سيبدأ بتدمير الرخص. **⇒ حذف الكود هو الإصلاح الصحيح، لا تصحيح المسار.**

⚠️ **الاستنتاج أعلاه مبني على توثيق المسار في `secure_license_storage.dart:14` + `getApplicationSupportDirectory()` — لم أشغّل التطبيق على جهاز للتحقق الميداني.**

### 🔧 الجزء 2 — إيقاف مسح `appVersion`

**`lib/services/license_manager.dart`** — تبديل الحذف بختم غير مُتلِف:

```dart
// قبل — كان يدمّر كل شيء
if (data != null && data.appVersion != _currentAppVersion) {
  AppLogger.i('... resetting license');
  await SecureLicenseStorage.clear();          // ⛔ يحذف الملف كاملاً
}

// بعد
if (data != null && data.appVersion != _currentAppVersion) {
  AppLogger.i('... stamping version, keeping license and firstRunDate intact');
  final stamped = data.copyWith(appVersion: _currentAppVersion);
  await SecureLicenseStorage.write(stamped);   // ✅ ختم في مكانه
}
```

**لماذا لم يكن عدّاد «100 سنة» وحده هو الخطر:** هذا الكود في فرع `FREE_VERSION` — **⇒ بناء مجاني كان يمكنه محو رخصة مدفوعة من نفس مجلد AppData.**

### 🐛 اكتشاف إضافي أثناء الاختبار — مفتاح احتياطي بطول خاطئ

**`lib/services/security_service.dart`:**

```dart
} catch (e) {
  _cachedKey = 'DEVELOPMENT_BACKUP_KEY_32_CHARS!!';   // ⛔ 33 حرفاً = 264 بت
}
```

| | |
|---|---|
| `'DEVELOPMENT_BACKUP_KEY_32_CHARS!!'` | **33 بايت** — Despite its name |
| `'POS2026-PROD-ENCRYPT-32-SECURE!!'` | 32 بايت ✅ |

**الأثر:** AES-256 لا يقبل سوى 128/192/256 بت ⇒ **كل `SecureLicenseStorage.write()` كانت تفشل صامتة** متى تعذّر `flutter_secure_storage`. **⇒ رخصة العميل المدفوع لا تُحفظ إطلاقاً.**

**الإصلاح:** توحيد الفرعين على ثابت واحد `_fallbackKey` بطول **32** بالضبط.
**⛔ لا تكلفة ترحيل:** لا يمكن أن يكون هناك أي ملف مُشفَّر بالمفتاح المعطوب — فالكتابة كانت تفشل دائماً.

**النطاق مؤكَّد:** `DatabaseEncryptionService` يستخدمه **الترخيص فقط** — لا النسخ الاحتياطي.
