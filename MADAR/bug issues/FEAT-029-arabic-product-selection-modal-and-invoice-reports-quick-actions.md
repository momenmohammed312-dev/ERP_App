## 2. ملخص المتطلبات

### أ. نافذة اختيار المنتج عند البيع (`ProductSelectionModal`):
1. **التعريب الكامل:** تحويل كافة النصوص الإنجليزية إلى العربية:
   - "Unit" -> "الوحدة" (مع تعريب قائمة الوحدات: قطعة، كيلو، كرتون، متر، لتر، طن).
   - "Quantity" -> "الكمية"
   - "Unit Price" -> "سعر الوحدة" (ومؤشر السعر الافتراضي "الافتراضي: ...").
   - "Discount" -> "الخصم"
   - "Tax" -> "الضريبة"
   - "Line Total" -> "إجمالي البند"
   - "Add to Invoice" -> "إضافة إلى الفاتورة"
   - "Cancel" -> "إلغاء"
   - "Stock" -> "المخزون المتوفر"
2. **العصرنة والتصميم الحديث (Modern Dark Theme):**
   - إزالة المربع الأبيض المنفصل الفاقع الخاص بـ Line Total وتنسيقه بلون داكن منسجم مع `MadarColors.bgCard` مع حدود خضراء ناعمة ونص الإجمالي باللون الأخضر الجذاب.
   - تحسين تناسق الحقول، الحواف الدائرية (16px)، الأيقونات المناسبة، وهوامش مريحة للعين.

### ب. صفحة تقارير المبيعات (`SalesReportTab`):
1. **أزرار المعاينة والتعديل المباشرة:**
   - إضافة أيقونة **العين (👁️)** في صف الفاتورة لعرض وتفقد تفاصيل الفاتورة بسرعة دون تعقيد (عبر نافذة تفاصيل حديثة أو توسيع مباشر).
   - إظهار أيقونة **التعديل (✏️)** مباشرة بجانب الأزرار لفتح شاشة تعديل الفاتورة `EditInvoicePage`.
   - إتاحة النقر على بطاقة الفاتورة مباشرة للمعاينة.
2. **تنظيف عرض اسم العميل:**
   - معالجة النصوص الداخلية للعملاء غير المحددين أو المتزامنين مثل `__SYNC_CUST_...` لتظهر كاسم لائق: "عميل نقدي" أو "عميل عام".
3. **تنظيم وتحديث شكل بطاقة الفاتورة:**
   - تباعد مريح للأيقونات مع Tooltips واضحة وألوان متناسقة، وتصميم بطاقة عصري يليق بنظام مدار.

## 3. خطة التنفيذ

1. **تعديل `lib/ui/invoice/widgets/product_selection_modal.dart`:**
   - استبدال النصوص الإنجليزية بالنصوص العربية السليمة.
   - إضافة دالة تعريب للوحدات: `localizeUnit(String unit)`.
   - إعادة تصميم صندوق الإجمالي `Line Total` ليتوافق مع الوضع الداكن ومظهر MADAR الحديث.
   - تحسين شكل زر الإضافة وزر الإلغاء.
2. **تعديل `lib/ui/reports/widgets/sales_report_tab.dart`:**
   - إضافة زر المعاينة السريعة (أيقونة العين 👁️) وزر التعديل السريع (✏️) في شريط أزرار الفاتورة.
   - إضافة دالة تنظيف اسم العميل `formatCustomerDisplayName`.
   - إنشاء نافذة معاينة الفاتورة السريعة `_showInvoicePreviewDialog` أو ربطها بالمعاينة المباشرة.
   - تحسين شريط العمليات والـ ExpansionTile ليصبح عصرياً وأكثر سلاسة.
3. **التحقق والاختبار:**
   - تشغيل `flutter analyze` والتأكد من خلو المشروع من أخطاء التحليل.
   - تشغيل اختبارات الوحدة ذات الصلة.
   - المزامنة مع GitHub و Notion.
